# JP GeoTech

Landing page para JP GeoTech enfocada en la promoción de un curso de inteligencia artificial aplicada a drones, SIG y monitoreo forestal.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Lucide React

## Secciones

- Hero principal con propuesta de valor
- Beneficios del curso
- Contenido del curso por módulos
- Público objetivo
- Proceso de acceso en 3 pasos
- Sección del instructor
- CTA final
- Footer con datos de contacto

## Desarrollo local

Requisitos:

- Node.js 20 o superior
- npm

Instalación:

```bash
npm install
```

Servidor de desarrollo:

```bash
npm run dev
```

Build de producción:

```bash
npm run build
```

Vista previa local de la build:

```bash
npm run preview
```
